# Eval: lever must be one

A valid `readout.md` must contain:

1. Exactly one blockquote lever (or one `**Lever:**` line).  
2. Sections **Not this** and **Yes this**.  
3. At least one anti-move bullet.  
4. ICP code in backticks.  
5. No heading like “10 tactics” / “recommended campaigns list”.  

Manual or script check on `reg-out/*/readout.md`.
