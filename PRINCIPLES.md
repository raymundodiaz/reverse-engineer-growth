## Growth rules (non-negotiable in this tool)

1. **One lever** per readout. If two compete, pick the one that blocks money.  
2. **Mechanism > symptom** (“we need more leads” is almost never the constraint).  
3. The map **opens** a paid audit; it does not replace it.  
4. **Anti-goals** are as sacred as goals.  
5. If overwhelmed: **stop adding**. Masters use minimum moves.  
6. Offer shape: **Problem → Promise → Proof → Proposition**.  
7. Offer design order: **Niche → Transformation → Price (~1/10 of value) → Mechanism → Channel**.  
8. B2B needs: no-brainer offer · interest-generating promotion · **predictable sales process**.  
9. Sequence: **Solution → Benefit → Result → Product** (not the reverse).  
10. Painkiller > vitamin > candy.  
11. If you sell “getting clients” and you can’t get clients → **stop; it’s fraud**.  
12. Quality ≠ list size → **ICP + intent signals**.  
13. Outbound → **diagnosis / IAC**, not package pitch.  
14. Content attacks **stagnation / failed tactics / trigger events**, not generic tips.  
15. Stagnation phases: denial → compulsive tactics → **trigger event** → cause search → fearful evaluation → decision.  
16. Trigger window ~**2–6 weeks** beats months of generic content.  
17. **Autopsy** when they already bought loose tactics.  
18. **IAC** = system index (multi-dimension), not a “marketing score”.  
19. Forward deployed: **recovered pesos / constraint**, not theater hours.  
20. After the map: **one** placement from the menu — or **nothing** (honest).

## Anti-patterns this tool must refuse

- 10-tactic laundry lists  
- “Run more ads” with no mechanism  
- Treating longest-running ads as proof of a healthy growth system  
- Confusing marketing activity with growth  
- Fake certainty where evidence is missing (use `unknowns`)
