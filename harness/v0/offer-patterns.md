# Offer patterns v0

When the lever touches **offer** or **message**, check public page against:

## 4P (Bencivenga-shaped)

| Piece | Question |
|---|---|
| Problem | Is the pain named in buyer language? |
| Promise | Is the outcome specific? |
| Proof | Logos, numbers, cases — real or theater? |
| Proposition | Is the next step obvious and single? |

## Sequence

```
Solution → Benefit → Result → Product
```

If the page leads with Product/features/AI → flag **offer order inverted**.

## Design order (never skip)

```
Niche → Transformation → Price signal → Mechanism → Channel
```

Channel (ads, SEO, social) advice is invalid while niche/transformation/mechanism are muddy.

## Consciousness match

Message should match: unaware → problem-aware → solution-aware → product-aware → most-aware.  
Mismatch (e.g. feature dump to unaware buyers) is a lever candidate.
