# Lever rules v0.2

## Must

1. Exactly **one** dominant lever sentence.  
2. **Not this (symptom)** vs **Yes this (mechanism)**.  
3. At least **one anti-move** (the obvious tactic that fails this constraint).  
4. ICP archetype set (`operator` | `system` | `scale` | `unknown`).  
5. Every factual claim in evidence has a source URL or is marked hypothesis.  
6. `unknowns` listed when evidence is thin.  
7. Prefer **painkiller** framing over vitamin/candy when naming the lever.  
8. If the free readout cannot name a mechanism → default CTA is **IAC**, not a tactic pack.  

## Must not

1. List of 5+ “recommended tactics” as the hero.  
2. “Run more ads / more content / hire SDRs” without a mechanism tied to the lever.  
3. Claiming channel winners from ad age alone.  
4. Inventing revenue, headcount, or CAC.  
5. Pitching a full product menu inside the free readout (placement = hint only).  
6. Confusing **marketing activity** with **growth** (channels ≠ constraint).  
7. Designing channel before niche → transformation → price → mechanism (offer order inverted).  

## ADEP check (before locking the lever)

- **A**lignment: does the public story match one buyer?  
- **D**iagnosis: is there a measurable system gap (or only vibes)?  
- **E**scalability: would the obvious tactic scale the bottleneck?  
- **P**riorities: is this the *one* thing, with explicit anti-goals?  

## Pattern sketches (examples, not auto-truth)

```
IF multi-product nav AND weak proof AND multi-CTA
THEN lever ≈ focus / offer clarity (entry door diluted)
ANTI ≈ more traffic before one offer

IF paid ads strong AND site/offer confuse
THEN lever ≈ message/offer, not budget
ANTI ≈ scale spend

IF founder is only closer AND growth claims scale
THEN lever ≈ owner-dependence / system
ANTI ≈ more lead gen into the same bottleneck

IF tool-salad narrative (CRM+ads+AI+courses) without one constraint
THEN lever ≈ compulsive-tactics phase → need diagnosis/autopsy path
ANTI ≈ add another tool

IF social proof is regional/mismatched to geo of the page
THEN lever ≈ trust/proof localization
ANTI ≈ more brand ads in the wrong market story

IF homepage is long and clever but no clear economic buyer path
THEN lever ≈ sales process / decision path unclear
ANTI ≈ more top-of-funnel content
```

## Offer-order reminder (when lever touches offer)

```
Niche → Transformation → Price (~1/10 value) → Mechanism → Channel
```

Never recommend Channel fixes before Mechanism/Niche are clear.

Human or denser L3 may override. Open harness is conservative.
