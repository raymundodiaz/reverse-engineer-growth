# Stagnation phases v0 (Ventaja)

| # | Phase | Public / conversational signals |
|---|---|---|
| 1 | Productive denial | Flat story blamed on “market”; more founder hours implied |
| 2 | Compulsive tactics | Tool salad on site (CRM+ads+AI+courses narrative); many vendors |
| 3 | Trigger event | Hiring freeze, key role open, competitor shoutouts, crisis posts |
| 4 | Cause search | Language shifts to systems, dependency, “why we don’t scale” |
| 5 | Fearful evaluation | Compares consultants; “we already tried” |
| 6 | Decision | Clear budget owner; asks for diagnosis not tips |

Phase 3 window is high value. Do not force a phase without signals → `unknown`.
