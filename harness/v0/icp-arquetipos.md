# ICP archetypes v0

Pick **exactly one** before naming the lever.

| Code | Signals (public proxies) | Misread |
|---|---|---|
| `operator` | Solo founder visible; thin process; offer still forming; personal brand heavy | Calling them enterprise |
| `system` | Multiple roles/pages; ops language; “depende de mí”; bought tools already | Treating as pure lead-gen ask |
| `scale` | Multi-site/multi-country; compliance; SLAs; committee language | Giving startup hacks |

If unclear → `unknown` and list what would classify them. Do not invent.
